# Handoff: browme コーポレートサイト（アイブロウ専門サロン）

## Overview
アイブロウ専門サロン **browme**（運営：株式会社Duo）のコーポレートサイト。TOP（1ページ完結型のコーポレート）と採用ページの2ページ構成。目的は (1) サロン／運営会社への信頼感醸成、(2) サービス・店舗の分かりやすい訴求、(3) 来店予約への誘導、(4) 求職者への職場魅力の訴求と応募ハードル低減。

## About the Design Files
このバンドル内の HTML ファイルは **HTMLで作成された「デザインリファレンス」** です。見た目と挙動の意図を示すプロトタイプであり、そのまま本番コードとして流用する前提のものではありません。タスクは、これらのデザインを **ターゲットのコードベースの既存環境（React / Next.js / Vue など）に、その環境の確立されたパターン・ライブラリを使って再現すること** です。環境がまだ存在しない場合は、プロジェクトに最適なフレームワーク（推奨: Next.js + TypeScript、静的書き出し可）を選定して実装してください。

> 注: `*.dc.html` は社内プロトタイピング形式（"Design Component"）です。`support.js` ランタイムと `{{ }}` テンプレート／`<sc-if>` `<sc-for>` 等の独自タグに依存しています。**これらの独自ランタイムは移植しないでください。** マークアップとインラインスタイルを「意味」として読み取り、通常の JSX/コンポーネントに書き直してください。

## Fidelity
**High-fidelity (hifi)**。最終的な配色・タイポグラフィ・余白・角丸・罫線・ホバー挙動まで作り込まれています。ピクセル精度で、コードベースの既存ライブラリ・パターンを用いて再現してください。スタイルはすべて **インラインstyle** で表現されているため、実装時は下記「Design Tokens」をCSS変数／テーマトークンに集約することを推奨します。

配色ルール: 背景はアイボリー基調、1〜2セクションのみ濃色帯（`#7B6E5D`）でリズムを作る。ゴールドは使わずブラウンベージュ系で上品に。写真と背景の同化を避けるため、写真枠には白背景／細枠／余白を確保。

### Typography
- 見出し（欧文装飾）: **'Playfair Display', serif**（weight 400–600）— セクションの英語見出し・番号・価格などの装飾に使用
- 見出し（和文）: **'Noto Serif JP', serif**（weight 400–600）— キャッチコピー・見出し
- 本文: **'Noto Sans JP', sans-serif**（weight 400/500/700）
- Google Fonts import 済み（各HTMLの `<head>` 参照）
- スケール例: セクション英字見出し 30px / letter-spacing 0.12em、和文サブ 12px / letter-spacing 0.28em、H2キャッチ clamp(22–30px)、本文 14–15px / line-height 1.9–2.1、キャプション 11–13px
- 最小文字サイズ: 本文 14px を下限に（高級感目的で小さくしすぎない）

### Spacing / Radius / Shadow
- セクション縦余白: **96px**（左右24px）、大型CTA下部は 128px
- コンテンツ最大幅: 1080px（テキスト主体セクションは 640–940px で中央寄せ）
- 角丸: カード **6px**、写真枠・ボタン **6px**、画像内 4px（強い丸みは使わない）
- 影: ごく淡いもののみ `0 1px 2px rgba(120,105,85,0.05)`、CTA `0 4px 14px rgba(140,122,99,0.28)`（強い影・グラデは不可）
- グリッド: `repeat(auto-fit, minmax(240–300px, 1fr))` + `gap: 20–24px`（モバイルで自動1カラム化）

### 共通コンポーネントルール
- **セクション見出し**: 中央寄せ。英語見出し(Playfair)＋和文サブ(字間広め)を、左右の細いライン（`height:1px`）で挟む。暗色帯上ではライン `rgba(255,255,255,0.28)`。
- **主要CTA**: 塗り `#8C7A63`（暗色帯上は明ベージュ文字）、白文字、angular 6px、太字、letter-spacing 0.08–0.12em。
- **補助CTA**: 白背景＋細枠 `1px solid #BBAF9C`、文字 `#504639`。
- **カード**: 白背景＋`1px solid #EDE7DB`＋淡影。ホバーで枠 `#C9BCA5`・背景 `#FCFAF6` にわずかに変化。
- **写真**: すべて `<image-slot>`（ドラッグ&ドロップ差し替え式プレースホルダー）。実装では通常の `<img>`／`next/image` に置換。現状はプレースホルダー中心。

### Animation
フェードイン・緩やかなスライドなど控えめな動きのみ。派手な演出・大きな移動は禁止。

## Pages / Screens

### 1. TOP（`Duo Corporate Site.dc.html`）
1ページ完結型。上から順に:
1. **Header（sticky）** — ロゴ「browme」＋小さく「株式会社Duo」。ナビ（About/Services/Locations/News/Recruit/Contact）＋「店舗一覧・予約」ボタン。モバイルはハンバーガー開閉（`menuOpen` state）。
2. **Hero** — 全面写真＋暗色グラデ（下→上）。ラベル「EYEBROW SALON browme」、H1「その眉が、あなたの印象になる。」、リード文。
3. **About Us（企業情報）** — 社名の由来・ミッション＋会社概要テーブル（会社名/代表者/所在地/設立/事業内容）＋代表メッセージカード＋写真。
4. **Services** — アイブロウ主体のサービスカード（施術内容・料金・所要時間）。before/after 合体画像の枠あり。
5. **Locations** — 濃色帯セクション。5店舗（大宮東口/大宮西口/上尾/栄/久屋）カード。各カード: 写真・店名・住所(〒)・アクセス・営業時間・定休日(年末年始12/30〜1/3)・支払い方法・「WEB予約」(主要CTA)＋「地図を見る」(補助CTA, Googleマップ)。※WEB予約リンクは大宮東口店のみHotPepper接続済み、他4店は問い合わせ暫定。
6. **News** — お知らせ3件（日付＋タグ＋見出し）。
7. **Recruit（採用導線）** — 明るいサロン内装バナー＋キャッチ、働く魅力3点、「採用情報を詳しく見る」CTA → 採用ページへ。
8. **Contact** — 個人/法人タブ切替フォーム（`tab` state、法人時は会社名欄を追加表示）。送信は擬似（`submitted` state）。
9. **Footer** — ロゴ・ナビ・コピーライト。

### 2. 採用ページ（`Duo Recruit.dc.html`）
1. **Header** — TOPへ戻る導線＋「応募する」CTA。
2. **Hero** — 写真＋「JOIN browme」＋キャッチ。
3. **Message** — サロンからのメッセージ（全幅・中央寄せ）。
4. **Why browme（働く4つの理由）** — カード4枚。
5. **browme in Numbers** — 濃色帯。数値を大きく見せる（※数値は要確認、下記参照）。
6. **スタッフの声（Voices）** — 3名横並びカード（イラスト・イニシャル氏名・役職・アイブロウ歴・タイトル・抜粋）。クリックで全文モーダル展開。登場: Y(山根)未経験/T(玉越)経験者/K(小山)マネージャー。
7. **スタッフの1日** — 施術の流れ写真＋タイムライン。
8. **求める人物像（Who We Want）** — 3カラムカード（番号→見出し→補足）。導入文「私たちは、こんな想いを持つ方と一緒に働きたいと考えています。」
9. **福利厚生・制度** — 制度カード。
10. **募集要項（Positions）** — 店舗スタッフ（アイブロウリスト）の要項テーブル。640–720px中央寄せ。

12. **FAQ** — Q&A。
13. **Entry CTA** — 「応募フォームへ」(主要)＋「募集要項を見る」(補助)。TOPの Contact へ接続。

## Interactions & Behavior
- ヘッダー: sticky、`scroll-behavior:smooth`＋`scroll-padding-top:72px` でアンカー遷移。モバイルメニュー開閉。
- Contactフォーム: 個人/法人タブでフォーム項目とボタン色を切替。送信で確認メッセージ表示（擬似・要API接続）。
- スタッフの声: カードクリックでモーダル全文表示（開閉state）。
- ページ間リンク: TOP ⇄ 採用ページ、採用の応募CTA → TOP#contact。
- レスポンシブ: グリッドは `auto-fit minmax` で自動段組み。モバイルは1カラム、ボタン最小高さ44–52px確保。

## State Management（実装時に必要な状態）
- `menuOpen`（ヘッダーメニュー） / Contactの `tab`（personal|business）・`submitted` / スタッフの声モーダルの開閉。
- フォーム送信は本番でバックエンド or フォームサービス（要選定）へ接続。

## Assets
- 写真はすべてプレースホルダー（`<image-slot>`）。本番では実サロン／スタッフ写真に差し替え。`uploads/` に取り込み済み素材があれば流用可（現状デザインは主にプレースホルダー状態）。
- スタッフの声のイラストも差し替え前提（タッチ統一）。
- アイコン類は未使用（装飾は最小）。

## ⚠ 確認が必要な項目（推測補完しないこと）
- About: 代表者名・設立年月の正式値
- browme in Numbers の数値（月収・勤続年数・取得率など）の正式な根拠値
- 大宮東口店以外4店舗の WEB予約 URL
- Contactフォームの送信先（メール／フォームサービス／CRM）
- 実写真・スタッフイラストの正式素材

## Recommended Implementation Notes
- Design Tokens をCSS変数（またはTailwind theme）に集約 → 全インラインstyleを置換。
- セクション見出し・カード・CTA・写真枠を再利用コンポーネント化（ページ独自スタイルを増やさない）。
- 静的中心のためNext.js（App Router, SSG）＋画像最適化を推奨。フォームのみ動的。
- アクセシビリティ: ボタン最小44px、写真上テキストは可読性確保（グラデ／シャドウ維持）。
